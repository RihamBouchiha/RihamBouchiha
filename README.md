<sub>CHAPTER 01</sub>

THE PERSON BEHIND THE CODE

</div>

I am a Computer Science Engineering student at ENIAD Berkane, specialising in Software Engineering and Artificial Intelligence.

I create digital products from end to end: from the first interface idea to backend architecture, APIs, databases and deployment.

What attracts me most is not one isolated field, but the connection between three worlds:

<br/>

DESIGN

I care about how technology feels.

I design clear, modern and human-centred interfaces where every interaction has a purpose.

<br/>

CODE

I care about how technology works.

I build complete web and mobile applications with clean architecture, reliable logic and maintainable code.

<br/>

INTELLIGENCE

I care about how technology can understand and assist.

I explore machine learning, deep learning, RAG systems and intelligent agents to create useful automation.

<br/>

I do not want to choose between code, design and intelligence.I want to understand how they amplify one another.
